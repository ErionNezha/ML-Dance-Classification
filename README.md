# 💃 Vallet Klasike Indiane (ML)

Notebook-u origjinal trajnon një **CNN (TensorFlow/Keras)** për klasifikimin e fotografive të 8 valleve klasike indiane (Bharatanatyam, Kathak, Kathakali, Kuchipudi, Odissi, Manipuri, Mohiniyattam, Sattriya). Demoja është **simulim edukativ**: mëso 8 vallet me karta përshkruese, pastaj testo veten në kuizin e klasifikimit me pikë.

## Si ta hapësh

Hap `index.html` në browser — tab-i **Live Demo** tregon demon funksionale, tab-i **Kodi Burim** tregon të gjithë kodin.

Ose hap direkt `demo/index.html` për demon.

## Struktura

- `index.html` — faqe showcase (Live Demo + Kodi Burim)
- `demo/` — demo/index.html (simulim), original/main.ipynb
- `original/` — burimi origjinal i paprekur
